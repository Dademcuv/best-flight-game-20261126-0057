**Skyline Courier** — a 3D flight game in the browser. Pilot a courier plane down a coastal valley: thread eight glowing rings over the lake and the ridges, watch your fuel, your stall margin and the terrain, then line up and land on the runway. Chase view over a living height-field landscape with snow-capped ranges, a lit instrument panel (attitude indicator, throttle and fuel gauges, vertical speed), a compass tape, and a HUD showing altitude, speed and heading at all times. Keyboard and mouse, generated engine and chime sounds, no downloads — every file is static and plays offline.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Controls: ↑/W and ↓/S climb and descend, ←→/A D bank and turn, Shift/Ctrl throttle, hold the mouse to steer, P pauses.
